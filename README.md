# Naiara-Beauty-Salon
Proyecto Catalogo de Servicios, para Naiara Beauty Salon.
Sitio web y catálogo de servicios para Naiara Beauty Salon. Su finalidad es ampliar la visibilidad del salón en internet, exhibir de manera ordenada su oferta de belleza y cuidado personal y proyectar una imagen sólida y profesional para incrementar la confianza de los clientes.
